# Yara · Reglas fundacionales

## 1. Nuestra misión

Que nunca sea demasiado tarde para aprender.
Que ninguna persona se quede atrás por no haber podido estudiar.

Aprenia es una plataforma educativa impulsada por inteligencia
artificial que busca recuperar oportunidades de aprendizaje.

## 2. Principios del proyecto

- Inclusión educativa: reducir barreras de acceso al aprendizaje.
- Aprendizaje personalizado: adaptar los itinerarios a cada persona.
- Accesibilidad: diseñar una experiencia sencilla, cálida y accesible.
- Igualdad de oportunidades: prestar especial atención a niñas y mujeres.
- Aprendizaje permanente: facilitar la formación durante toda la vida.
- Tecnología responsable: utilizar la IA como herramienta de apoyo educativo.
- Modularidad: construir una arquitectura preparada para crecer.
- Colaboración: trabajar mediante GitHub, ramas, Issues y Pull Requests.

## 3. Personas a las que queremos ayudar

Aprenia prioriza:

- Niños y niñas que necesitan refuerzo educativo.
- Jóvenes que quieren recuperar sus estudios.
- Mujeres adultas que desean retomar su formación.
- Personas mayores que necesitan desarrollar competencias.

## 4. Funcionalidades fundamentales

El agente educativo deberá poder:

1. Comprender las necesidades y objetivos educativos.
2. Diseñar itinerarios de aprendizaje personalizados.
3. Explicar contenidos y crear ejercicios adaptativos.
4. Recomendar cursos, becas y recursos formativos.
5. Registrar objetivos, progreso y próximos pasos.

## 5. Accesibilidad e inclusión

- Interfaz sencilla y comprensible.
- Adaptación visual para diferentes necesidades.
- Posibilidad de cambiar el idioma.
- Alternativas de acceso que reduzcan barreras.
- Atención a personas con discapacidad visual.

## 6. Arquitectura de referencia

- Frontend: React / Next.js.
- Backend: FastAPI.
- Agente educativo: LLM con herramientas.
- Datos: catálogo de cursos y oportunidades.
- Persistencia: usuarios, itinerarios y progreso.
- Despliegue: aplicación web accesible.

## 7. Herramientas del agente

- assess_learning_needs
- search_learning_opportunities
- create_learning_path

## 8. Organización del trabajo

- Las nuevas funcionalidades se desarrollan en ramas independientes.
- Los cambios se integran mediante Pull Requests.
- Los PR deben explicar qué cambian y por qué.
- Se revisa el código antes de integrarlo.
- No se modifica directamente main.
- Se mantiene una documentación clara y actualizada.

## 9. Objetivos de impacto

Aprenia contribuye a:

- ODS 4: Educación de calidad.
- ODS 5: Igualdad de género.
- ODS 8: Trabajo decente.
- ODS 10: Reducción de desigualdades.
- ODS 17: Alianzas para lograr los objetivos.
